---
title: "App route map"
description: "Map documentation breadcrumbs to Festie route patterns."
---

Route examples use these placeholders:

- `:festivalSubdomain` is the festival link.
- `:subFestSlug` is the subfest slug.
- `:programCode` is a programme code.

## Festival routes

| Breadcrumb | Route pattern |
| --- | --- |
| `Festival > Home` | `/:festivalSubdomain/home` |
| `Festival > Fests` | `/:festivalSubdomain/fests` |
| `Festival > Users` | `/:festivalSubdomain/users` |
| `Festival > Resource` | `/:festivalSubdomain/resource` |
| `Festival > Website` | `/:festivalSubdomain/website` |
| `Festival > Billing` | `/:festivalSubdomain/billing` |
| `Festival > Settings` | `/:festivalSubdomain/settings` |
