---
title: "Schedule conflicts"
description: "Review and resolve venue or judge conflicts."
---

Conflicts appear when schedules overlap in a way that needs review, such as two programmes using the same venue at the same time.

## Prerequisites

- Programmes are scheduled.
- You have admin access.

Open `Subfest > Schedule > Conflicts`.

<Steps>
  <Step title="Review the conflict list">
    Check each conflict and identify the affected programmes.
  </Step>
  <Step title="Fix the schedule">
    Change the programme time, venue, or judge from the schedule.
  </Step>
  <Step title="Return to conflicts">
    Confirm the conflict no longer applies, or mark it resolved if you handled it outside the schedule.
  </Step>
</Steps>

<Warning>
  Mark a conflict resolved only after you have confirmed the event team can run that schedule.
</Warning>
