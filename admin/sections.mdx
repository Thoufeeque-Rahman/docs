---
title: "Sub categories"
description: "Create sets such as class or department, limit them to categories, and assign candidates."
---

Sub categories group candidates beyond team and main category. A set (for example `Class`) holds items (`1`, `2`, `3`). A candidate can be in one item per set.

## Prerequisites

- Candidates are added or imported.
- Categories exist if you want to limit a set to some of them.

Open `Subfest > Candidate > Sub Categories`.

<Steps>
  <Step title="Create a set">
    Add a set such as `Class`, `Stream`, or `Department`.
  </Step>
  <Step title="Add items">
    Add items such as `1`, `2`, `3`, or `Science`, `Maths`.
  </Step>
  <Step title="Choose categories">
    Keep **All categories**, or pick the main categories the set applies to. Use **Scope** on a set to change this later.
  </Step>
  <Step title="Assign candidates">
    Assign from the candidate form, the bulk **Add to sub category** action, or by chest number.
  </Step>
</Steps>

<Note>
  If you narrow a set's categories, assignments of candidates in the removed categories are cleared. You see the count first. Changing a candidate's category also clears sub categories that no longer apply.
</Note>

## Filters

Each set appears as its own filter, named after the set, with its items as options. Use them on candidates, registrations, schedules and reports.
