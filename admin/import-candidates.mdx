---
title: "Import candidates"
description: "Import candidates from Excel and fix rows during preview."
---

Use import when you have many candidates to add.

## Prerequisites

- Categories and teams already exist.
- Your candidate data is ready in a spreadsheet.

Open `Subfest > Candidate`, then choose the import option.

<Steps>
  <Step title="Download the sample file">
    Download the example Excel file from the import page.
  </Step>
  <Step title="Fill the spreadsheet">
    Add candidate names, teams, categories, and other required fields.
  </Step>
  <Step title="Upload the file">
    Upload the completed Excel file.
  </Step>
  <Step title="Preview the import">
    Review the imported rows. Fix any mistakes directly in the preview instead of editing the Excel file again.
  </Step>
  <Step title="Save the import">
    Save the preview and review how many rows succeeded or failed.
  </Step>
</Steps>

<Warning>
  Do not skip the preview. It is the best place to catch wrong teams, categories, or duplicate details before saving.
</Warning>
