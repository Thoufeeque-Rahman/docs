---
title: "Import Candidates"
description: "Bulk import candidates using Excel and manage duplicates."
---

If you have a large number of candidates to add, adding them one-by-one can be tedious. Festie provides a bulk import option using Excel.

## Prerequisites

- Categories and Teams must already exist in Festie.
- Your candidate data is organized in a spreadsheet.

Navigate to `Subfest > Candidates` and click the **Import** button.

---

## Import Configuration Options

Before uploading your file, Festie gives you two important options:

1. **Override Existing:** 
   Check this box if you are re-uploading data to fix mistakes. If a Chest Number in your Excel file matches a candidate already in the system, Festie will update (override) their existing profile with the new data from the spreadsheet instead of creating a duplicate. This is extremely useful if you realize you assigned students to the wrong team and want to quickly fix it via Excel.
   
2. **Auto Generate Chest Number:**
   If you haven't assigned chest numbers in your Excel file, check this box. Festie will automatically generate and assign chest numbers to the imported candidates based on your system rules.

---

## The Import Process

<Steps>
  <Step title="Download the Sample Excel">
    Download the provided sample Excel file from the import page. This file contains the exact column structure Festie needs.
  </Step>
  <Step title="Prepare Your Data">
    Fill the sample spreadsheet with your candidates' names, teams, categories, and other details. Save the file.
  </Step>
  <Step title="Upload the File">
    Drag and drop your completed Excel file into the import area.
  </Step>
  <Step title="Preview and Edit">
    Once uploaded, you will see a preview of all the candidates to be imported. 
    You can directly edit any mistakes, add new rows, or delete rows right from this preview screen without needing to go back to Excel.
  </Step>
  <Step title="Save the Import">
    Click **Save**. A confirmation message will show that the candidates were successfully added, and they will now appear in your Candidates list.
  </Step>
</Steps>
