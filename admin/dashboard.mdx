The dashboard is the first page you should check after creating a subfest.

## Prerequisites

- You have created a festival and opened a subfest.
- You have admin access.

Open `Subfest > Dashboard`.

The dashboard shows setup tasks, festival details, counts, recent registrations, result progress, and analytics. Use it as the checklist for what to configure next.

<Steps>
  <Step title="Review pending tasks">
    Check which setup items are still incomplete.
  </Step>
  <Step title="Prepare setup data">
    Configure categories, teams, criteria, chest rules, candidates, programmes, collections, and curbs.
  </Step>
  <Step title="Track event progress">
    After setup, use the dashboard to review programme count, candidate count, registrations, result entry, and recent activity.
  </Step>
</Steps>

<Tip>
  Return to the dashboard after each major setup area. It helps you see whether the festival is ready for registration and results.
</Tip>
