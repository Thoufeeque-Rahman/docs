---
title: "Curbs"
description: "Limit how many programmes candidates can join by category and collection."
---

Curbs define participation limits. For example, you can limit how many Bidaya category stage programmes one candidate can join.

## Prerequisites

- Categories are ready.
- Programme collections are ready if the curb applies to a collection.

Open `Subfest > Programme > Curbs`.

<Steps>
  <Step title="Create a curb">
    Add a name, such as `Bidaya stage limit`.
  </Step>
  <Step title="Choose candidate category">
    Select the candidate category the curb applies to.
  </Step>
  <Step title="Choose programme category">
    Select the programme category the limit applies to.
  </Step>
  <Step title="Choose a collection if needed">
    Select a collection such as `Stage` if the limit applies only to that programme group.
  </Step>
  <Step title="Set min and max values">
    Enter the minimum and maximum allowed programmes.
  </Step>
  <Step title="Save the curb">
    Create the curb and use reports later to review compliance.
  </Step>
</Steps>

<Note>
  In the transcript source, a maximum value of `0` means unlimited.
</Note>
