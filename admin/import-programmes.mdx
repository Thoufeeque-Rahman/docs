---
title: "Import programmes"
description: "Import programme data from Excel."
---

Use programme import when you have a prepared list of competitions.

## Prerequisites

- Categories and criteria are ready.
- Programme codes and names are finalized.

Open `Subfest > Programme`, then choose import.

<Steps>
  <Step title="Download the sample file">
    Download the example Excel file.
  </Step>
  <Step title="Fill programme rows">
    Add programme code, name, type, category, judgement type, and registration details.
  </Step>
  <Step title="Upload and preview">
    Upload the file and review the preview page.
  </Step>
  <Step title="Fix preview issues">
    Correct any invalid or missing values shown in preview.
  </Step>
  <Step title="Save the import">
    Save the valid rows.
  </Step>
</Steps>
