---
title: "Candidate chest number rules"
description: "Configure automatic chest number generation for candidates."
---

Chest numbers identify candidates across registrations, sheets, results, and reports.

## Prerequisites

- You have admin access.
- You know whether chest numbers should be automatic or manual.

Open the chest number rules setup from the dashboard task.

<Steps>
  <Step title="Review the default rule">
    Festie provides a simple rule for generating chest numbers.
  </Step>
  <Step title="Adjust the rule if needed">
    Change the rule format to match your festival's numbering style.
  </Step>
  <Step title="Disable auto generation when needed">
    Turn off automatic generation if admins will enter chest numbers manually.
  </Step>
</Steps>

<Tip>
  Decide this before importing candidates. It is easier than correcting many candidate records later.
</Tip>
