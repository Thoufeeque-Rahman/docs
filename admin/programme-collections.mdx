---
title: "Programme Collections"
description: "Group programmes into specific collections to organize reports and apply participation limits."
---

Collections allow you to group multiple programmes together for filtering, reporting, and applying participation limits (Curbs). For example, you can group all stage performances into a "Stage" collection and all writing events into a "Non-stage" collection.

## Prerequisites

- Your programmes have already been created or imported.
- You have decided how you want to categorize them (e.g., Stage vs Non-stage, Type A vs Type B).

Navigate to `Subfest > Programmes > Collections`.

## Managing Collections

<Steps>
  <Step title="Create a Collection">
    By default, you might see collections like `Stage` or `Non-stage`. To create a new one, click to add a collection and give it a name (e.g., `Type A Programmes`).
  </Step>
  <Step title="Assign Programmes to the Collection">
    Once the collection is created, open it and click **Add Programme**. 
    Select all the programmes that belong to this specific collection (e.g., select all Type A programmes) and add them.
  </Step>
  <Step title="Review the Collection">
    Check the list inside the collection to ensure the correct programmes were added.
  </Step>
</Steps>

## Why use Collections?

1. **Filtering Reports:** Later, when you want to print team sheets or view results, you can easily filter to show only "Stage" programmes.
2. **Applying Curbs:** If you want to limit candidates to participating in a maximum of 3 "Stage" programmes, you need a "Stage" collection set up first so you can apply the limit specifically to that collection.

<Tip>
  Always create your collections *before* setting up your Curbs (participation limits), as you will need to select the collection when building the limit rule.
</Tip>
