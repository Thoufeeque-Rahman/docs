---
title: "Results entry"
description: "Enter positions, grades, or scores for programmes."
---

Result entry records the outcome of each programme.

## Prerequisites

- Programmes have registrations.
- The programme judgement type is configured.
- Position and grade criteria are ready if used.

Open `Subfest > Results`.

<Steps>
  <Step title="Open a programme">
    Select a programme marked as not entered or needing result entry.
  </Step>
  <Step title="Enter result values">
    For manual result, select positions and grades. For manual score, enter the score values required by the programme.
  </Step>
  <Step title="Review calculated points">
    Check the automatically calculated points before saving.
  </Step>
  <Step title="Save results">
    Save the result entry.
  </Step>
</Steps>

<Note>
  Saving results does not automatically publish them to the public website. Use result release when ready.
</Note>
