---
title: "Categories & Teams"
description: "Fetch competition categories, age brackets, participating teams, and house colors."
---

Categories divide festival participants into age or grade groups (e.g. Sub Junior, Junior, General). Teams represent participating houses, clubs, or institutions.

## List Categories

Retrieve categories defined within a specific sub-festival.

```http
GET /public-api/v1/categories
```

### Query Parameters

| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `subFestId` | `UUID` | Optional* | Target sub-festival ID (*required if not passing `subFestSlug`). |
| `subFestSlug` | `string` | Optional* | Target sub-festival URL slug. |
| `search` | `string` | No | Case-insensitive search across category name and description. |
| `page` | `integer` | No | Page number (default: `1`). |
| `limit` | `integer` | No | Items per page (default: `20`, max: `20`). |
| `sortBy` | `string` | No | Sort field: `displayOrder`, `name`. |
| `sortOrder` | `string` | No | Direction: `ASC` or `DESC`. |

### Example Request

```bash
curl -X GET "https://api.festie.app/public-api/v1/categories?subFestSlug=arts-2026" \
  -H "X-API-Key: YOUR_API_KEY"
```

## List Teams

Retrieve participating teams, houses, or departments in the subfest.

```http
GET /public-api/v1/teams
```

### Query Parameters

| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `subFestId` | `UUID` | Optional* | Sub-festival identifier. |
| `subFestSlug` | `string` | Optional* | Sub-festival URL slug. |
| `search` | `string` | No | Search term matching team name or display name. |
| `colorCode` | `string` | No | Filter by assigned hex color code (e.g. `#EF4444`). |
| `hasCandidates` | `boolean` | No | Filter teams that have registered candidates (`true` or `false`). |
| `page` | `integer` | No | Page number (default: `1`). |
| `limit` | `integer` | No | Items per page (max `20`). |
| `sortBy` | `string` | No | Sort field: `displayOrder`, `name`. |
| `sortOrder` | `string` | No | Direction: `ASC` or `DESC`. |

### Example Request

```bash
curl -X GET "https://api.festie.app/public-api/v1/teams?subFestSlug=arts-2026" \
  -H "X-API-Key: YOUR_API_KEY"
```
