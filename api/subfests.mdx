title: "SubFests & Metadata Filters"
description: "Retrieve sub-festivals, levels, and aggregated metadata filter options for building UI dropdowns."
---

Festivals in Festie can organize events into sub-festivals (such as Seniors, Juniors, Sahityotsav, or SportFest). Use these endpoints to discover available subfests and fetch global dropdown filter options.

## List SubFests

Retrieve active sub-festivals associated with your festival.

```http
GET /public-api/v1/subfests
```

### Query Parameters

| Parameter | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `search` | `string` | — | Filter subfests by name or slug. |
| `levelId` | `UUID` | — | Filter subfests belonging to a specific festival hierarchy level. |
| `status` | `string` | `ACTIVE` | Filter status (`ACTIVE`). |
| `page` | `integer` | `1` | Page number for pagination. |
| `limit` | `integer` | `20` | Number of items per page (max `20`). |
| `sortBy` | `string` | `name` | Sort field: `name`, `slug`, `status`. |
| `sortOrder` | `string` | `ASC` | Sort direction: `ASC` or `DESC`. |

### Example Request

<CodeGroup>
```bash cURL
curl -X GET "https://api.festie.app/public-api/v1/subfests?page=1&limit=10" \
  -H "X-API-Key: YOUR_API_KEY"
```

```typescript TypeScript
const response = await fetch(
  "https://api.festie.app/public-api/v1/subfests?page=1&limit=10",
  {
    headers: { "X-API-Key": process.env.FESTIE_API_KEY! },
  }
);
const result = await response.json();
```
</CodeGroup>

## Get Filter Metadata

Fetch aggregated metadata for building search filters and dropdown controls in your application, including categories, teams, and venues.

```http
GET /public-api/v1/filters
```

### Query Parameters

| Parameter | Type | Description |
| :--- | :--- | :--- |
| `subFestId` | `UUID` | *(Optional)* Target a specific subfest. |
| `subFestSlug` | `string` | *(Optional)* Target a specific subfest by its URL slug. |

### Example Request

```bash
curl -X GET "https://api.festie.app/public-api/v1/filters?subFestSlug=arts-2026" \
  -H "X-API-Key: YOUR_API_KEY"
```
