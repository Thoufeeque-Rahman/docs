title: "Summary & Toppers"
description: "Fetch overall festival metadata, counts, statistics, and individual or team topper standings."
---

These endpoints provide high-level festival statistics and counts, configured topper award categories, and live leaderboard standings for individuals and teams (such as Kalaprathibha, Kalathilakam, Category champions, or Team champions).

## Festival Summary & Statistics

Retrieve global festival metadata and real-time aggregate counters for programmes, participants, galleries, news, and downloads.

```http
GET /public-api/v1/summary
```

### Query Parameters

| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `subFestSlug` | `string` | No | Limit counts and context to a specific sub-festival slug. |
| `subFestId` | `UUID` | No | Limit counts and context to a specific sub-festival ID. |

### Example Request

```bash
curl -X GET "https://api.festie.app/public-api/v1/summary?subFestSlug=arts-2026" \
  -H "X-API-Key: YOUR_API_KEY"
```

## List Topper Placeholders

Topper placeholders represent the award categories configured in your festival (e.g., Overall Individual Champion, Junior Category Champion, Overall House Trophy). Query this endpoint to discover available placeholder IDs.

```http
GET /public-api/v1/topper-placeholders
```

### Query Parameters

| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `subFestSlug` | `string` | Required* | Sub-festival slug (*required if no `subFestId`). |
| `subFestId` | `UUID` | Required* | Sub-festival UUID. |
| `isPublished` | `boolean` | No | Filter by published status (`true` by default). |
| `entityType` | `string` | No | Filter by target entity: `CANDIDATE` or `TEAM`. |
| `scopeType` | `string` | No | Scope type: `GLOBAL`, `CATEGORY`, `SECTION`, `TEAM`. |
| `page` | `integer` | No | Pagination page number (default: `1`). |
| `limit` | `integer` | No | Items per page (default: `20`, max: `20`). |

### Example Request

```bash
curl -X GET "https://api.festie.app/public-api/v1/topper-placeholders?subFestSlug=arts-2026" \
  -H "X-API-Key: YOUR_API_KEY"
```

## Get Topper Entries

Retrieve the computed rankings and awarded points for candidates or teams assigned to a specific topper placeholder.

```http
GET /public-api/v1/toppers
```

### Query Parameters

| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `topperPlaceholderId` | `UUID` | Yes | **Required.** The UUID of the topper placeholder to fetch rankings for. |
| `subFestSlug` | `string` | No | Sub-festival slug. |
| `subFestId` | `UUID` | No | Sub-festival identifier. |
| `page` | `integer` | No | Pagination page number (default: `1`). |
| `limit` | `integer` | No | Items per page (default: `20`, max: `20`). |

### Example Request

```bash
curl -X GET "https://api.festie.app/public-api/v1/toppers?topperPlaceholderId=cb8edb2d-9d63-40e5-b082-516d7cbce961&subFestSlug=arts-2026" \
  -H "X-API-Key: YOUR_API_KEY"
```

## Page Toppers (Aggregated Leaderboard)

Retrieve all topper placeholders and their active ranking entries configured for a subfest or website page. This is the primary endpoint used by website leaderboards and stage walls to display multiple standings in one call.

```http
GET /public-api/v1/page-toppers
```

### Query Parameters

| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `subFestSlug` | `string` | Optional* | Sub-festival slug. |
| `subFestId` | `UUID` | Optional* | Sub-festival UUID. |
| `pageSlug` | `string` | No | Optional website page slug to filter placeholders assigned to that page. |
| `placeholderId` | `UUID` | No | Optional placeholder ID filter. |
| `scopeType` | `string` | No | Optional scope type filter: `GLOBAL`, `CATEGORY`, `SECTION`, `TEAM`. |

### Example Request

```bash
curl -X GET "https://api.festie.app/public-api/v1/page-toppers?subFestSlug=arts-2026" \
  -H "X-API-Key: YOUR_API_KEY"
```
