These endpoints provide high-level festival statistics, real-time team point leaderboards, and individual topper standings (such as Kalathilakam, Kalaprathibha, or category toppers).

## Festival Summary & Team Leaderboard

Retrieve an aggregated overview of the festival including live team scores, rank standings, and event counters.

```http
GET /public-api/v1/summary
```

### Query Parameters

| Parameter | Type | Description |
| :--- | :--- | :--- |
| `subFestId` | `UUID` | Optional: limit summary to a specific sub-festival. |
| `subFestSlug` | `string` | Optional: limit summary by sub-festival slug. |

### Example Request

```bash
curl -X GET "https://api.festie.app/public-api/v1/summary?subFestSlug=arts-2026" \
  -H "X-API-Key: YOUR_API_KEY"
```

## Get Topper Entries

Retrieve top-performing candidates or teams assigned to title placeholders (e.g. Festival Champion, Best Actor, Category Toppers).

```http
GET /public-api/v1/toppers
```

### Query Parameters

| Parameter | Type | Description |
| :--- | :--- | :--- |
| `topperPlaceholderId` | `UUID` | Filter entries by specific title placeholder. |
| `subFestSlug` | `string` | Sub-festival slug. |
| `page` | `integer` | Page number. |
| `limit` | `integer` | Items per page (max: `20`). |

### Example Request

```bash
curl -X GET "https://api.festie.app/public-api/v1/toppers?subFestSlug=arts-2026" \
  -H "X-API-Key: YOUR_API_KEY"
```

### Example Response

```json
{
  "data": [
    {
      "id": "top-01",
      "rank": 1,
      "points": 35,
      "candidate": {

      }
```

## List Topper Placeholders

Query the configured topper award titles and categories.

```http
GET /public-api/v1/topper-placeholders
```

### Query Parameters

| Parameter | Type | Description |
| :--- | :--- | :--- |
| `isPublished` | `boolean` | Filter published titles (`true`). |
| `entityType` | `string` | Target entity: `CANDIDATE` or `TEAM`. |
| `scopeType` | `string` | Title scope: `FESTIVAL`, `SUBFEST`, or `CATEGORY`. |
| `page` | `integer` | Page number. |
| `limit` | `integer` | Items per page (max: `20`). |

## Page Toppers
