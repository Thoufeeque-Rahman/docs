Festie provides real-time result endpoints for querying official scores, winner rankings (1st, 2nd, 3rd), grades (A, B, C), and team point allocations.

## Get Programme Result

Retrieve published results for an individual programme by passing its programme code or ID.

```http
GET /public-api/v1/programme-result
```

### Query Parameters

| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `programCode` | `string` | Optional* | Programme code (e.g. `LIT-01`). |
| `subFestProgramId` | `UUID` | Optional* | SubFest programme UUID. |
| `subFestSlug` | `string` | Optional* | Sub-festival URL slug (*required if passing `programCode`). |
| `subFestId` | `UUID` | Optional | Sub-festival UUID. |

### Example Request

```bash
curl -X GET "https://api.festie.app/public-api/v1/programme-result?programCode=LIT-01&subFestSlug=arts-2026" \
  -H "X-API-Key: YOUR_API_KEY"
```

## List Multiple Programme Results

Retrieve results for multiple programmes with pagination and filters.

```http
GET /public-api/v1/programme-results
```

### Query Parameters

Supports all filters available in `GET /public-api/v1/programmes` (such as `categoryIds`, `venues`, `search`, `page`, `limit`).

### Example Request

```bash
curl -X GET "https://api.festie.app/public-api/v1/programme-results?subFestSlug=arts-2026&page=1&limit=10" \
  -H "X-API-Key: YOUR_API_KEY"
```
