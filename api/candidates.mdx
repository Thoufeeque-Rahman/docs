title: "Candidates (Participants)"

Candidates are the registered students or participants competing in your festival. Festie provides comprehensive candidate endpoints with support for chest number pattern lookups, team/category filtering, registration histories, and scored results.

## List Candidates

Search and filter candidates across a sub-festival.

```http
GET /public-api/v1/candidates
```

### Query Parameters

| Parameter | Type | Description |
| :--- | :--- | :--- |
| `subFestId` | `UUID` | *(Required if no slug)* Sub-festival identifier. |
| `subFestSlug` | `string` | *(Required if no ID)* Sub-festival URL slug. |
| `search` | `string` | Search candidate name, chest number, or admission number. |
| `categoryIds` | `string` | Comma-separated list of category UUIDs. |
| `teamIds` | `string` | Comma-separated list of team UUIDs. |
| `gender` | `string` | Filter by gender: `MALE`, `FEMALE`, `OTHER`. |
| `chestNoPattern` | `string` | Filter by chest number prefix or pattern (e.g. `10*`). |
| `admNoPattern` | `string` | Filter by student admission number pattern. |
| `hasAvatar` | `boolean` | Filter candidates who have uploaded profile photos. |
| `hasRegistration` | `boolean` | Filter candidates registered for at least one programme. |
| `page` | `integer` | Page number (default `1`). |
| `limit` | `integer` | Page limit (max `20`). |

### Example Request

```bash
curl -X GET "https://api.festie.app/public-api/v1/candidates?subFestSlug=arts-2026&search=Aisha&page=1&limit=10" \
  -H "X-API-Key: YOUR_API_KEY"
```

## Get Candidate Detail

Retrieve comprehensive biographical, team, category, and point details for a specific candidate.

```http
GET /public-api/v1/candidate-detail
```

### Query Parameters

| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `subFestCandidateId` | `UUID` | Yes | The unique SubFest Candidate identifier. |
| `subFestId` | `UUID` | Optional | Sub-festival identifier. |
| `subFestSlug` | `string` | Optional | Sub-festival URL slug. |

### Example Request

```bash
curl -X GET "https://api.festie.app/public-api/v1/candidate-detail?subFestCandidateId=f92df06f-f989-45d6-ae69-20422d0f9504" \
```

## Get Candidate Results

Look up a candidate's published scorecards, awarded positions, grades, and total contributed points using their chest number or candidate ID.

```http
GET /public-api/v1/candidate-result
```

### Query Parameters

| Parameter | Type | Description |
| :--- | :--- | :--- |
| `chestNo` | `string` | The participant's assigned chest number (e.g. `104`). |
| `subFestCandidateId` | `UUID` | Alternative: look up by candidate UUID. |
| `subFestSlug` | `string` | *(Recommended)* Sub-festival slug. |

### Example Request

```bash
curl -X GET "https://api.festie.app/public-api/v1/candidate-result?chestNo=104&subFestSlug=arts-2026" \
  -H "X-API-Key: YOUR_API_KEY"
```
