Festie helps you run a festival from setup to published results. You can create a festival, add categories, teams, candidates, programmes, rules, registrations, schedules, results, reports, templates, and a public website.

The main workflow starts with the festival owner or admin. Team managers, judges, and media users can join after the admin grants access.

## Recommended setup order

<Steps>
  <Step title="Create the festival">
    Sign in, create a festival, choose your festival type, and start your trial.
  </Step>
  <Step title="Prepare the data">
    Set categories, teams, criteria, chest number rules, candidates, sections, programmes, collections, and curbs.
  </Step>
  <Step title="Open registrations">
    Add team managers, open programme registrations, register participants, and collect topics where needed.
  </Step>
  <Step title="Run the event">
    Download judgement sheets, create schedules, resolve conflicts, enter results, and publish releases.
  </Step>
  <Step title="Share and review">
    Publish the website, download reports, review toppers, and manage billing.
  </Step>
</Steps>

<Note>
  This documentation uses app breadcrumbs such as `Subfest > Schedule > Conflicts`. These match the visible sidebar labels in Festie.
</Note>
