ഒരുപാട് ആളുകളെ ആഡ് ചെയ്യാനുണ്ടെങ്കിൽ ഓരോരുത്തരായി എന്റർ ചെയ്യുന്നത് ബുദ്ധിമുട്ടായിരിക്കും. അതിനായി Festie-ൽ Excel വഴി bulk import ചെയ്യാനുള്ള ഓപ്ഷൻ ഉണ്ട്.

## വേണ്ട കാര്യങ്ങൾ

- ഫെസ്റ്റിവലിൽ Categories, Teams എന്നിവ മുൻപേ ആഡ് ചെയ്തിരിക്കണം.
- നിങ്ങളുടെ ആളുകളുടെ വിവരങ്ങൾ Excel-ൽ ആക്കിയിരിക്കണം.

`Subfest > Candidates` എടുത്ത് **Import** ബട്ടണിൽ ക്ലിക്ക് ചെയ്യുക.

---

## Import ചെയ്യുമ്പോഴുള്ള ഓപ്ഷനുകൾ

ഫയൽ അപ്‌ലോഡ് ചെയ്യുന്നതിന് മുൻപായി Festie രണ്ട് പ്രധാന ഓപ്ഷനുകൾ ചോദിക്കും:

1. **Override Existing:** 
   ആഡ് ചെയ്ത ഡാറ്റയിലെ തെറ്റുകൾ തിരുത്താനാണ് നിങ്ങൾ വീണ്ടും അപ്‌ലോഡ് ചെയ്യുന്നതെങ്കിൽ ഇത് ടിക്ക് ചെയ്യുക. ഇതിലൂടെ, Excel-ലെ Chest Number സിസ്റ്റത്തിലുള്ള ഒരാളുടേതുമായി മാച്ച് ആയാൽ, പുതിയ ആളായി ആഡ് ചെയ്യുന്നതിന് പകരം പഴയ പ്രൊഫൈലിലെ വിവരങ്ങൾ Excel-ലെ പുതിയ ഡാറ്റ വെച്ച് മാറ്റി നൽകും. (ഉദാഹരണത്തിന്, കുട്ടികളുടെ ടീം മാറിയത് പെട്ടെന്ന് തിരുത്താൻ ഇത് ഉപയോഗിക്കാം).
   
2. **Auto Generate Chest Number:**
   നിങ്ങളുടെ Excel ഫയലിൽ chest numbers കൊടുത്തിട്ടില്ലെങ്കിൽ ഇത് ടിക്ക് ചെയ്യുക. നിങ്ങൾ സെറ്റ് ചെയ്ത റൂൾ വെച്ച് Festie അവർക്ക് തനിയെ നമ്പറുകൾ നൽകിക്കോളും.

## Import ചെയ്യുന്ന രീതി

<Steps>
  <Step title="Sample Excel ഡൗൺലോഡ് ചെയ്യുക">
    Import പേജിൽ കൊടുത്തിട്ടുള്ള sample Excel ഫയൽ ഡൗൺലോഡ് ചെയ്യുക. Festie-യ്ക്ക് വേണ്ട കൃത്യമായ കോളങ്ങൾ ഇതിൽ ഉണ്ടായിരിക്കും.
  </Step>
  <Step title="ഡാറ്റ എന്റർ ചെയ്യുക">
    നിങ്ങളുടെ candidates-ന്റെ പേര്, ടീം, കാറ്റഗറി തുടങ്ങിയ വിവരങ്ങൾ ആ Excel-ൽ ടൈപ്പ് ചെയ്ത് സേവ് ചെയ്യുക.
  </Step>
  <Step title="ഫയൽ അപ്‌ലോഡ് ചെയ്യുക">
    നിങ്ങൾ സേവ് ചെയ്ത Excel ഫയൽ import ഏരിയയിലേക്ക് drag & drop ചെയ്യുക.
  </Step>
  <Step title="പരിശോധിക്കുക (Preview)">
    അപ്‌ലോഡ് ചെയ്ത ഉടനെ തന്നെ ആഡ് ചെയ്യാൻ പോകുന്ന ആളുകളുടെ വിവരങ്ങൾ സ്ക്രീനിൽ കാണാം. 
    അതിൽ എന്തെങ്കിലും തെറ്റുണ്ടെങ്കിൽ തിരുത്താനോ, പുതിയതായി ഒരാളെ ആഡ് ചെയ്യാനോ, ഡിലീറ്റ് ചെയ്യാനോ Excel എടുക്കാതെ തന്നെ അവിടെ വെച്ച് സാധിക്കും.
  </Step>
  <Step title="സേവ് ചെയ്യാം">
    **Save** ക്ലിക്ക് ചെയ്യുക. വിജയകരമായി ആഡ് ചെയ്തു എന്ന മെസ്സേജ് വരികയും, എല്ലാവരെയും Candidates ലിസ്റ്റിൽ കാണുകയും ചെയ്യാം.
  </Step>
</Steps>
