Festie-യിൽ മൂന്ന് രീതിയിലാണ് റിസൾട്ടുകൾ നൽകാൻ സാധിക്കുക: **Manual Result**, **Manual Score**, **Online Judgement**.

## 1. Manual Result (ഏറ്റവും വേഗത്തിൽ ചെയ്യാൻ)
ജഡ്ജസ് പേപ്പറിൽ റിസൾട്ട് എല്ലാം കണ്ടുപിടിച്ച് വെച്ചിട്ടുണ്ടെങ്കിൽ, ആർക്കാണ് 1st, 2nd, 3rd കിട്ടിയതെന്ന് പെട്ടെന്ന് ടൈപ്പ് ചെയ്ത് കൊടുക്കാൻ ഈ രീതി ഉപയോഗിക്കാം.

1. `Subfest > Results` ഓപ്പൺ ചെയ്യുക.
2. പ്രോഗ്രാം സെലക്ട് ചെയ്ത ശേഷം അതിന്റെ judgement type **Manual Result** ആണെന്ന് ഉറപ്പുവരുത്തുക.
3. രജിസ്റ്റർ ചെയ്ത കുട്ടികളുടെ ലിസ്റ്റ് അവിടെ കാണാം.
4. വിജയികളായ കുട്ടികളുടെ നേരെ Position (ഉദാ: First), Grade (ഉദാ: A Grade) എന്നിവ കൊടുക്കുക.
5. **Save Result** ക്ലിക്ക് ചെയ്യുക.

## 2. Manual Score (കണക്കുകൂട്ടി റിസൾട്ട് ഉണ്ടാക്കാൻ)
പല ജഡ്ജസ് നൽകിയ മാർക്കുകൾ സിസ്റ്റം തന്നെ കൂട്ടി റിസൾട്ട് (1st, 2nd, 3rd) കണ്ടുപിടിക്കണമെങ്കിൽ ഈ രീതി ഉപയോഗിക്കാം.

1. `Subfest > Results` ഓപ്പൺ ചെയ്യുക.
2. ഒരു പ്രോഗ്രാം സെലക്ട് ചെയ്ത് അതിന്റെ judgement type **Manual Score** ആക്കുക.
3. **Manage Judges** ക്ലിക്ക് ചെയ്ത് ജഡ്ജസിനെ ആഡ് ചെയ്യുക (ഉദാ: Judge A, Judge B, Judge C).
4. ഓരോ ജഡ്ജിനും നൽകാവുന്ന പരമാവധി മാർക്ക് എത്രയാണെന്ന് കൊടുക്കുക (ഉദാ: 10 അല്ലെങ്കിൽ 20).
5. ഇനി ഓരോ കുട്ടിക്കും ഓരോ ജഡ്ജും നൽകിയ മാർക്കുകൾ എന്റർ ചെയ്യുക.
6. **Save Changes** ക്ലിക്ക് ചെയ്ത ശേഷം **Generate Result** കൊടുക്കുക.
7. Festie തനിയെ മാർക്കുകൾ കൂട്ടി 1st, 2nd, 3rd സ്ഥാനങ്ങൾ കണ്ടുപിടിച്ചു നൽകും!

<Note>
  ഇവിടെ റിസൾട്ട് സേവ് ചെയ്തത് കൊണ്ട് മാത്രം പബ്ലിക് വെബ്സൈറ്റിൽ കാണിക്കില്ല. എല്ലാവർക്കും കാണണമെങ്കിൽ Result Release ഫീച്ചർ ഉപയോഗിക്കേണ്ടതുണ്ട്.
</Note>
