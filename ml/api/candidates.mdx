ഫെസ്റ്റിവലിൽ രജിസ്റ്റർ ചെയ്തിട്ടുള്ള കുട്ടികളുടെയും മത്സരാർത്ഥികളുടെയും വിവരങ്ങൾ ലഭ്യമാക്കുന്ന എൻഡ്പോയിന്റുകൾ. ചെസ്റ്റ് നമ്പർ, കാറ്റഗറി, ടീം എന്നിവ വെച്ചുള്ള ഫിൽട്ടറിംഗ്, പങ്കെടുത്ത മത്സരങ്ങൾ, നേടിയ പോയിന്റുകൾ എന്നിവ ഇതിലൂടെ ലഭിക്കും.

## മത്സരാർത്ഥികളുടെ ലിസ്റ്റ് (List Candidates)

ഒരു സബ് ഫെസ്റ്റിവലിലെ മത്സരാർത്ഥികളെ തിരയാനും ഫിൽട്ടർ ചെയ്യാനും:

```http
GET /public-api/v1/candidates
```

### Query Parameters

| Parameter | Type | വിവരണം |
| :--- | :--- | :--- |
| `subFestId` | `UUID` | സബ് ഫെസ്റ്റ് ഐഡി (*സ്ലഗ് ഇല്ലെങ്കിൽ നിർബന്ധം). |
| `subFestSlug` | `string` | സബ് ഫെസ്റ്റ് സ്ലഗ്. |
| `search` | `string` | പേര്, ചെസ്റ്റ് നമ്പർ, അഡ്മിഷൻ നമ്പർ എന്നിവ തിരയാൻ. |
| `categoryIds` | `string` | കാറ്റഗറി ഐഡികൾ (കോമ നൽകി വേർതിരിച്ചത്). |
| `teamIds` | `string` | ടീം ഐഡികൾ. |
| `gender` | `string` | ലിംഗം: `MALE`, `FEMALE`, `OTHER`. |
| `chestNoPattern` | `string` | ചെസ്റ്റ് നമ്പർ പാറ്റേൺ (ഉദാ: `10*`). |
| `admNoPattern` | `string` | അഡ്മിഷൻ നമ്പർ പാറ്റേൺ. |
| `hasAvatar` | `boolean` | പ്രൊഫൈൽ ഫോട്ടോ ഉള്ളവർ മാത്രം (`true`/`false`). |
| `hasRegistration` | `boolean` | മത്സരങ്ങളിൽ രജിസ്റ്റർ ചെയ്തവർ മാത്രം. |
| `page` | `integer` | പേജ് നമ്പർ (ഡിഫോൾട്ട്: `1`). |
| `limit` | `integer` | ഓരോ പേജിലെയും എണ്ണം (പരമാവധി `20`). |

### ഉദാഹരണം

```bash
curl -X GET "https://api.festie.app/public-api/v1/candidates?subFestSlug=arts-2026&search=Aisha&page=1&limit=10" \
  -H "X-API-Key: YOUR_API_KEY"
```

## കാൻഡിഡേറ്റ് വിശദവിവരങ്ങൾ (Candidate Detail)

ഒരു പ്രത്യേക മത്സരാർത്ഥിയുടെ പൂർണ്ണ വിവരങ്ങളും നിലവിലെ പോയിന്റുകളും ലഭിക്കാൻ:

```http
GET /public-api/v1/candidate-detail
```

### Query Parameters

| Parameter | Type | നിർബന്ധമാണോ | വിവരണം |
| :--- | :--- | :--- | :--- |
| `subFestCandidateId` | `UUID` | നിർബന്ധം | SubFest Candidate ഐഡി. |
| `subFestId` | `UUID` | അല്ല | സബ് ഫെസ്റ്റ് ഐഡി. |
| `subFestSlug` | `string` | അല്ല | സബ് ഫെസ്റ്റ് സ്ലഗ്. |

### ഉദാഹരണം

```bash
curl -X GET "https://api.festie.app/public-api/v1/candidate-detail?subFestCandidateId=f92df06f-f989-45d6-ae69-20422d0f9504" \
```

```http
GET /public-api/v1/candidate-registrations
```

## ഫലങ്ങളും പോയിന്റുകളും (Candidate Results)

ചെസ്റ്റ് നമ്പർ അല്ലെങ്കിൽ ഐഡി നൽകി മത്സരാർത്ഥി നേടിയ സ്ഥാനങ്ങൾ (1st, 2nd, 3rd), ഗ്രേഡുകൾ (A, B), ആകെ പോയിന്റുകൾ എന്നിവ പരിശോധിക്കാൻ:

```http
GET /public-api/v1/candidate-result
```

### Query Parameters

| Parameter | Type | വിവരണം |
| :--- | :--- | :--- |
| `chestNo` | `string` | മത്സരാർത്ഥിയുടെ ചെസ്റ്റ് നമ്പർ (ഉദാ: `104`). |
| `subFestCandidateId` | `UUID` | കാൻഡിഡേറ്റ് സിസ്റ്റം ഐഡി. |
| `subFestSlug` | `string` | *(ശുപാർശ ചെയ്യുന്നത്)* സബ് ഫെസ്റ്റ് സ്ലഗ്. |

### ഉദാഹരണം

```bash
curl -X GET "https://api.festie.app/public-api/v1/candidate-result?chestNo=104&subFestSlug=arts-2026" \
```
