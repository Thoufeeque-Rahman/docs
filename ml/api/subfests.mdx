Festie-ൽ ഒരു ഫെസ്റ്റിവലിനെ വിവിധ സബ് ഫെസ്റ്റിവലുകളായി (ഉദാ: സീനിയേഴ്സ്, ജൂനിയേഴ്സ്, സാഹിത്യോത്സവ്) തരംതിരിക്കാം. ലഭ്യമായ സബ് ഫെസ്റ്റിവലുകളുടെ ലിസ്റ്റും സെർച്ച് ഡ്രോപ്പ്ഡൗണുകൾക്കുള്ള ഡാറ്റയും ലഭിക്കാൻ ഈ API-കൾ ഉപയോഗിക്കാം.

## സബ് ഫെസ്റ്റിവലുകളുടെ ലിസ്റ്റ് (List SubFests)

നിങ്ങളുടെ ഫെസ്റ്റിവലിലുള്ള സജീവ സബ് ഫെസ്റ്റിവലുകൾ ലഭിക്കാൻ:

```http
GET /public-api/v1/subfests
```

### Query Parameters

| Parameter | Type | ഡിഫോൾട്ട് | വിവരണം |
| :--- | :--- | :--- | :--- |
| `search` | `string` | — | പേരോ സ്ലഗ്ഗോ വെച്ച് തിരയാൻ. |
| `levelId` | `UUID` | — | പ്രത്യേക ഫെസ്റ്റിവൽ ലെവലിലുള്ളവ മാത്രം ലഭിക്കാൻ. |
| `status` | `string` | `ACTIVE` | സ്റ്റാറ്റസ് ഫിൽട്ടർ (`ACTIVE`). |
| `page` | `integer` | `1` | പേജ് നമ്പർ. |
| `limit` | `integer` | `20` | ഓരോ പേജിലെയും എണ്ണം (പരമാവധി `20`). |
| `sortBy` | `string` | `name` | സോർട്ട് ചെയ്യേണ്ട ഫീൽഡ്: `name`, `slug`, `status`. |
| `sortOrder` | `string` | `ASC` | ക്രമം: `ASC` അല്ലെങ്കിൽ `DESC`. |

### ഉദാഹരണം

<CodeGroup>
```bash cURL
curl -X GET "https://api.festie.app/public-api/v1/subfests?page=1&limit=10" \
  -H "X-API-Key: YOUR_API_KEY"
```

```typescript TypeScript
const response = await fetch(

const result = await response.json();
```

## ഫിൽട്ടർ മെറ്റാഡാറ്റ (Filter Metadata)

നിങ്ങളുടെ ആപ്ലിക്കേഷനിലെ സെർച്ച് ബോക്സുകൾ, കാറ്റഗറി / ടീം / വേദി ഡ്രോപ്പ്ഡൗണുകൾ എന്നിവ തയ്യാറാക്കാൻ ആവശ്യമായ സമഗ്ര വിവരങ്ങൾ ലഭിക്കാൻ:

```http
GET /public-api/v1/filters
```

### Query Parameters

| Parameter | Type | വിവരണം |
| :--- | :--- | :--- |
| `subFestId` | `UUID` | *(ഐച്ഛികം)* നിർദ്ദിഷ്ട സബ് ഫെസ്റ്റ് ഐഡി. |
| `subFestSlug` | `string` | *(ഐച്ഛികം)* സബ് ഫെസ്റ്റ് URL സ്ലഗ്. |

### ഉദാഹരണം

```bash
curl -X GET "https://api.festie.app/public-api/v1/filters?subFestSlug=arts-2026" \
  -H "X-API-Key: YOUR_API_KEY"
```
