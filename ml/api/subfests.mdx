Festie-യിൽ ഒരു ഫെസ്റ്റിവലിന് കീഴിൽ ഒന്നിൽക്കൂടുതൽ സബ് ഫെസ്റ്റുകൾ (ഉദാ: ജൂനിയർ, സീനിയർ, ആർട്സ്, സ്പോർട്സ്) ഉണ്ടാകാം. ലഭ്യമായ സബ് ഫെസ്റ്റുകൾ കണ്ടെത്താനും, നിങ്ങളുടെ ആപ്പുകളിലെ ഡ്രോപ്ഡൗൺ ഫിൽട്ടറുകൾ സെറ്റ് ചെയ്യാനും ഈ API-കൾ ഉപയോഗിക്കാം.

## സബ് ഫെസ്റ്റുകളുടെ ലിസ്റ്റ്

നിങ്ങളുടെ ഫെസ്റ്റിവലിലുള്ള ആക്ടീവ് ആയ സബ് ഫെസ്റ്റുകളുടെ വിവരങ്ങൾ എടുക്കുക.

```http
GET /public-api/v1/subfests
```

### Query Parameters

| Parameter | Type | Default | വിവരണം |
| :--- | :--- | :--- | :--- |
| `search` | `string` | — | പേരോ സ്ലഗ്ഗോ (slug) ഉപയോഗിച്ച് തിരയാൻ. |
| `levelId` | `UUID` | — | നിർദ്ദിഷ്ട ലെവലിലുള്ള സബ് ഫെസ്റ്റുകൾ ഫിൽട്ടർ ചെയ്യാൻ. |
| `status` | `string` | `ACTIVE` | സ്റ്റാറ്റസ് പ്രകാരം ഫിൽട്ടർ ചെയ്യാൻ. |
| `page` | `integer` | `1` | പേജ് നമ്പർ. |
| `limit` | `integer` | `20` | ഒരു പേജിൽ പരമാവധി എത്രയെണ്ണം (പരമാവധി `20`). |

### ഉദാഹരണം

```bash
curl -X GET "https://api.festie.app/public-api/v1/subfests?page=1&limit=10" \
  -H "X-API-Key: YOUR_API_KEY"
```

## Filter വിവരങ്ങൾ ലഭിക്കാൻ

നിങ്ങളുടെ ആപ്പിലോ വെബ്സൈറ്റിലോ കാറ്റഗറികൾ, ടീമുകൾ, വേദികൾ (venues) എന്നിവയുടെ ഡ്രോപ്ഡൗൺ ലിസ്റ്റ് ഉണ്ടാക്കാൻ ആവശ്യമായ വിവരങ്ങൾ ഒരൊറ്റ കോളിൽ ലഭിക്കാൻ ഇത് ഉപയോഗിക്കാം.

```http
GET /public-api/v1/filters
```

### Query Parameters

| Parameter | Type | വിവരണം |
| :--- | :--- | :--- |
| `subFestId` | `UUID` | നിർദ്ദിഷ്ട സബ് ഫെസ്റ്റ് ഐഡി. |
| `subFestSlug` | `string` | സബ് ഫെസ്റ്റ് സ്ലഗ്. |

### ഉദാഹരണം

```bash
curl -X GET "https://api.festie.app/public-api/v1/filters?subFestSlug=sahityotsav-2026" \
  -H "X-API-Key: YOUR_API_KEY"
```
