ഫെസ്റ്റിവലിന്റെ ആകെ സ്റ്റാറ്റിസ്റ്റിക്സുകൾ (പ്രോഗ്രാമുകൾ, കുട്ടികൾ, ഗ്യാലറി മുതലായവയുടെ എണ്ണം), സെറ്റ് ചെയ്തിട്ടുള്ള ടോപ്പർ അവാർഡ് കാറ്റഗറികൾ, കലാപ്രതിഭ/കലാതിലകം അല്ലെങ്കിൽ ടീം ചാമ്പ്യന്മാരുടെ ലൈവ് പോയിന്റ് നില എന്നിവ ഈ API-കൾ വഴി ലഭിക്കും.

## ഫെസ്റ്റിവൽ സമറിയും കൗണ്ടുകളും (Summary)

ഫെസ്റ്റിവലിന്റെ മെറ്റാഡാറ്റയും, മത്സരങ്ങളുടെയും രജിസ്ട്രേഷനുകളുടെയും തത്സമയ കൗണ്ടുകളും ലഭിക്കാൻ:

```http
GET /public-api/v1/summary
```

### Query Parameters

| Parameter | Type | നിർബന്ധമാണോ | വിവരണം |
| :--- | :--- | :--- | :--- |
| `subFestSlug` | `string` | അല്ല | ഒരു നിർദ്ദിഷ്ട സബ് ഫെസ്റ്റിവലിലെ വിവരങ്ങൾ മാത്രമായി ചുരുക്കാൻ. |
| `subFestId` | `UUID` | അല്ല | സബ് ഫെസ്റ്റ് സിസ്റ്റം ഐഡി. |

### ഉദാഹരണം

```bash
curl -X GET "https://api.festie.app/public-api/v1/summary?subFestSlug=arts-2026" \
  -H "X-API-Key: YOUR_API_KEY"
```

## ടോപ്പർ കാറ്റഗറികൾ (Placeholders)

ഫെസ്റ്റിവലിൽ നിർവ്വചിച്ചിട്ടുള്ള ടോപ്പർ അവാർഡുകളുടെ ലിസ്റ്റ് (ഉദാ: കലാപ്രതിഭ, കലാതിലകം, ജനറൽ ചാമ്പ്യൻഷിപ്പ്) അറിയാൻ:

```http
GET /public-api/v1/topper-placeholders
```

### Query Parameters

| Parameter | Type | നിർബന്ധമാണോ | വിവരണം |
| :--- | :--- | :--- | :--- |
| `subFestSlug` | `string` | നിർബന്ധം* | സബ് ഫെസ്റ്റ് സ്ലഗ് (*`subFestId` നൽകിയിട്ടില്ലെങ്കിൽ). |
| `subFestId` | `UUID` | നിർബന്ധം* | സബ് ഫെസ്റ്റ് സിസ്റ്റം ഐഡി. |
| `isPublished` | `boolean` | അല്ല | പബ്ലിഷ് ചെയ്തവ മാത്രം കാണിക്കാൻ (`true`). |
| `entityType` | `string` | അല്ല | ടാർഗെറ്റ് എന്റിറ്റി: `CANDIDATE` അല്ലെങ്കിൽ `TEAM`. |
| `scopeType` | `string` | അല്ല | സ്കോപ്പ്: `GLOBAL`, `CATEGORY`, `SECTION`, `TEAM`. |
| `page` | `integer` | അല്ല | പേജ് നമ്പർ (ഡിഫോൾട്ട്: `1`). |
| `limit` | `integer` | അല്ല | പരമാവധി എണ്ണം (ഡിഫോൾട്ട്: `20`, പരമാവധി: `20`). |

### ഉദാഹരണം

```bash
curl -X GET "https://api.festie.app/public-api/v1/topper-placeholders?subFestSlug=arts-2026" \

```

## ടോപ്പർ റാങ്കിംഗ് ലിസ്റ്റ് (Topper Entries)

ഒരു പ്രത്യേക ടോപ്പർ അവാർഡിലേക്ക് (Placeholder) നിലവിൽ ഒന്നാമതോ തുടർന്നുള്ള സ്ഥാനങ്ങളിലോ ഉള്ള പ്രതിഭകളുടെയോ ടീമുകളുടെയോ പോയിന്റ് നില ലഭിക്കാൻ:

```http
GET /public-api/v1/toppers
```

### Query Parameters

| Parameter | Type | നിർബന്ധമാണോ | വിവരണം |
| :--- | :--- | :--- | :--- |
| `topperPlaceholderId` | `UUID` | നിർബന്ധം | **നിർബന്ധം.** ടോപ്പർ പ്ലേസ്‌ഹോൾഡറിന്റെ UUID. |
| `subFestSlug` | `string` | അല്ല | സബ് ഫെസ്റ്റ് സ്ലഗ്. |
| `subFestId` | `UUID` | അല്ല | സബ് ഫെസ്റ്റ് ഐഡി. |
| `page` | `integer` | അല്ല | പേജ് നമ്പർ (ഡിഫോൾട്ട്: `1`). |
| `limit` | `integer` | അല്ല | ഓരോ പേജിലെയും എണ്ണം (ഡിഫോൾട്ട്: `20`, പരമാവധി: `20`). |

```bash
curl -X GET "https://api.festie.app/public-api/v1/toppers?topperPlaceholderId=cb8edb2d-9d63-40e5-b082-516d7cbce961&subFestSlug=arts-2026" \
```

## പേജ് ടോപ്പർമാർ (Page Toppers)

ഒരു സബ് ഫെസ്റ്റിവലിലെ അല്ലെങ്കിൽ ഒരു പ്രത്യേക വെബ്‌സൈറ്റ് പേജിലെ എല്ലാ ടോപ്പർമാരുടെയും പോയിന്റ് നില ഒരൊറ്റ കോളിൽ ലഭ്യമാക്കാൻ:

```http
GET /public-api/v1/page-toppers
```

### Query Parameters

| Parameter | Type | നിർബന്ധമാണോ | വിവരണം |
| :--- | :--- | :--- | :--- |
| `subFestSlug` | `string` | നിർബന്ധം* | സബ് ഫെസ്റ്റ് സ്ലഗ്. |
| `subFestId` | `UUID` | നിർബന്ധം* | സബ് ഫെസ്റ്റ് ഐഡി. |
| `pageSlug` | `string` | അല്ല | വെബ് പേജ് സ്ലഗ് ഫിൽട്ടർ. |
| `placeholderId` | `UUID` | അല്ല | പ്രത്യേക പ്ലേസ്‌ഹോൾഡർ ഐഡി. |
| `scopeType` | `string` | അല്ല | സ്കോപ്പ്: `GLOBAL`, `CATEGORY`, `SECTION`, `TEAM`. |

### ഉദാഹരണം

```bash
curl -X GET "https://api.festie.app/public-api/v1/page-toppers?subFestSlug=arts-2026" \
```
