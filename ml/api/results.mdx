മത്സരങ്ങളുടെ ഔദ്യോഗിക സ്കോറുകൾ, വിജയികൾ (1st, 2nd, 3rd), ഗ്രേഡുകൾ (A, B, C), ടീം പോയിന്റുകൾ എന്നിവ തത്സമയം അറിയാൻ Festie റിസൾട്ട് API-കൾ ഉപയോഗിക്കാം.

## പ്രോഗ്രാം റിസൾട്ട് (Get Programme Result)

പ്രോഗ്രാം കോഡ് നൽകി ഒരു പ്രത്യേക മത്സരത്തിന്റെ ഫലങ്ങൾ അറിയാൻ:

```http
GET /public-api/v1/programme-result
```

### Query Parameters

| Parameter | Type | നിർബന്ധമാണോ | വിവരണം |
| :--- | :--- | :--- | :--- |
| `programCode` | `string` | നിർബന്ധം | പ്രോഗ്രാം കോഡ് (ഉദാ: `LIT-01`). |
| `subFestSlug` | `string` | ഓപ്ഷണൽ | സബ് ഫെസ്റ്റ് സ്ലഗ്. |
| `subFestId` | `UUID` | ഓപ്ഷണൽ | സബ് ഫെസ്റ്റ് ഐഡി. |

### ഉദാഹരണം

```bash
curl -X GET "https://api.festie.app/public-api/v1/programme-result?programCode=LIT-01" \
  -H "X-API-Key: YOUR_API_KEY"
```

## ഒന്നിലധികം മത്സര ഫലങ്ങൾ (List Multiple Results)

പ്രഖ്യാപിച്ച വിവിധ മത്സര ഫലങ്ങൾ പേജിനേഷൻ വഴി ഒരുമിച്ച് ലഭിക്കാൻ:

```http
GET /public-api/v1/programme-results
```

### Query Parameters

| Parameter | Type | വിവരണം |
| :--- | :--- | :--- |
| `subFestId` | `UUID` | സബ് ഫെസ്റ്റ് ഐഡി (*സ്ലഗ് ഇല്ലെങ്കിൽ നിർബന്ധം). |
| `subFestSlug` | `string` | സബ് ഫെസ്റ്റ് സ്ലഗ്. |
| `categoryIds` | `string` | കാറ്റഗറി ഐഡികൾ. |
| `search` | `string` | മത്സരത്തിന്റെ പേര് അല്ലെങ്കിൽ കോഡ്. |
| `page` | `integer` | പേജ് നമ്പർ (ഡിഫോൾട്ട്: `1`). |
| `limit` | `integer` | ഓരോ പേജിലെയും എണ്ണം (പരമാവധി `20`). |

### ഉദാഹരണം

```bash
curl -X GET "https://api.festie.app/public-api/v1/programme-results?subFestSlug=arts-2026&page=1&limit=10" \
  -H "X-API-Key: YOUR_API_KEY"
```
