ഫെസ്റ്റിവലിലെ വിവിധ മത്സര ഇനങ്ങളെയാണ് പ്രോഗ്രാമുകൾ എന്ന് വിളിക്കുന്നത് (ഉദാ: പ്രസംഗം, കഥാരചന, ശാസ്ത്രീയ നൃത്തം). മത്സരങ്ങൾ ഏത് വേദിയിൽ, എപ്പോൾ നടക്കുന്നു എന്ന് നിശ്ചയിക്കുന്നതാണ് ഷെഡ്യൂളുകൾ.

## മത്സരങ്ങളുടെ ലിസ്റ്റ് (List Programmes)

ഒരു സബ് ഫെസ്റ്റിവലിലെ മത്സരങ്ങൾ ഫിൽട്ടർ ചെയ്തു ലഭിക്കാൻ:

```http
GET /public-api/v1/programmes
```

### Query Parameters

| Parameter | Type | വിവരണം |
| :--- | :--- | :--- |
| `subFestId` | `UUID` | സബ് ഫെസ്റ്റ് ഐഡി (*സ്ലഗ് ഇല്ലെങ്കിൽ നിർബന്ധം). |
| `subFestSlug` | `string` | സബ് ഫെസ്റ്റ് സ്ലഗ്. |
| `search` | `string` | മത്സരത്തിന്റെ പേരോ കോഡോ വെച്ച് തിരയാൻ. |
| `categoryIds` | `string` | കാറ്റഗറി ഐഡികൾ (കോമ നൽകി വേർതിരിച്ചത്). |
| `venues` | `string` | വേദി ഐഡികൾ. |
| `status` | `string` | മത്സര സ്റ്റാറ്റസ്: `DRAFT`, `REGISTRATION_OPEN`, `SCHEDULED`, `ONGOING`, `JUDGEMENT_COMPLETED`, `RESULTS_ENTERED`, `RESULTS_PUBLISHED`. |
| `programType` | `string` | മത്സര രീതി: `SINGLE`, `GROUP`, `COMBINED`. |
| `programCodePattern` | `string` | കോഡ് പാറ്റേൺ (ഉദാ: `OFF-*`, `ON-*`). |
| `collectionId` | `UUID` | നിർദ്ദിഷ്ട കളക്ഷൻ ഐഡി. |
| `hasSchedule` | `boolean` | സ്റ്റേജ് ഷെഡ്യൂൾ ചെയ്തവ മാത്രം. |
| `hasResults` | `boolean` | റിസൾട്ട് പ്രഖ്യാപിച്ചവ മാത്രം. |
| `page` | `integer` | പേജ് നമ്പർ (ഡിഫോൾട്ട്: `1`). |
| `limit` | `integer` | ഓരോ പേജിലെയും എണ്ണം (പരമാവധി: `20`). |

### ഉദാഹരണം

```bash
curl -X GET "https://api.festie.app/public-api/v1/programmes?subFestSlug=arts-2026&status=RESULTS_PUBLISHED&limit=10" \
  -H "X-API-Key: YOUR_API_KEY"
```

## മത്സരത്തിന്റെ പൂർണ്ണ വിവരങ്ങൾ (Programme Detail)

ഒരു നിർദ്ദിഷ്ട മത്സരത്തിന്റെ വിശദാംശങ്ങൾ ലഭിക്കാൻ:

```http
GET /public-api/v1/programme-detail
```

### Query Parameters

| Parameter | Type | നിർബന്ധമാണോ | വിവരണം |
| :--- | :--- | :--- | :--- |
| `programCode` | `string` | നിർബന്ധം | മത്സരത്തിന്റെ കോഡ് (ഉദാ: `LIT-01`). |
| `subFestId` | `UUID` | അല്ല | സബ് ഫെസ്റ്റ് ഐഡി. |
| `subFestSlug` | `string` | അല്ല | സബ് ഫെസ്റ്റ് സ്ലഗ്. |

### ഉദാഹരണം

```bash
curl -X GET "https://api.festie.app/public-api/v1/programme-detail?programCode=LIT-01&subFestSlug=arts-2026" \
```

## സമയക്രമം (List Schedules)

വേദികളിലെ സ്റ്റേജ് ടൈംടേബിളുകൾ ലഭിക്കാൻ. ലൈവ് സൈനേജ് ബോർഡുകൾക്കും സ്റ്റേജ് ഡിസ്പ്ലേകൾക്കും ഇത് ഉപയോഗിക്കാം:

```http
GET /public-api/v1/schedules
```

### Query Parameters

| Parameter | Type | വിവരണം |
| :--- | :--- | :--- |
| `subFestId` | `UUID` | സബ് ഫെസ്റ്റ് ഐഡി (*സ്ലഗ് ഇല്ലെങ്കിൽ നിർബന്ധം). |
| `subFestSlug` | `string` | സബ് ഫെസ്റ്റ് സ്ലഗ്. |
| `venueId` | `UUID` | നിർദ്ദിഷ്ട വേദി ഫിൽട്ടർ. |
| `programCode` | `string` | മത്സരത്തിന്റെ കോഡ് (ഉദാ: `LIT-01`) നൽകി ഫിൽട്ടർ ചെയ്യാൻ. |
| `subFestProgramId` | `UUID` | പ്രോഗ്രാം സിസ്റ്റം ഐഡി വഴി ഫിൽട്ടർ ചെയ്യാൻ. |
| `scheduledAtFrom` | `ISO Date` | ഈ സമയത്തിന് ശേഷം ആരംഭിക്കുന്നവ. |
| `scheduledAtTo` | `ISO Date` | ഈ സമയത്തിന് മുൻപ് ആരംഭിക്കുന്നവ. |
| `page` | `integer` | പേജ് നമ്പർ (ഡിഫോൾട്ട്: `1`). |
| `limit` | `integer` | ഓരോ പേജിലെയും എണ്ണം (പരമാവധി `20`). |

### ഉദാഹരണം

```bash
curl -X GET "https://api.festie.app/public-api/v1/schedules?subFestSlug=arts-2026&scheduledAtFrom=2026-09-08T00:00:00.000Z" \
  -H "X-API-Key: YOUR_API_KEY"
```
