ഫെസ്റ്റിവലുമായി ബന്ധപ്പെട്ട ഔദ്യോഗിക പത്രക്കുറിപ്പുകൾ, സ്റ്റേജ് ഫോട്ടോകൾ, മത്സര നിയമാവലികൾ എന്നിവ ആപ്ലിക്കേഷനിലേക്ക് നേരിട്ട് നൽകാൻ Festie മീഡിയ API-കൾ സഹായിക്കുന്നു.

## വാർത്തകളും അറിയിപ്പുകളും (List News)

പബ്ലിഷ് ചെയ്ത ഫെസ്റ്റിവൽ വാർത്തകളും ബുള്ളറ്റിനുകളും അറിയാൻ:

```http
GET /public-api/v1/news
```

### Query Parameters

| Parameter | Type | വിവരണം |
| :--- | :--- | :--- |
| `search` | `string` | വാർത്താ തലക്കെട്ടിലോ സംഗ്രഹത്തിലോ തിരയാൻ. |
| `tags` | `string` | ടാഗുകൾ (കോമ നൽകി വേർതിരിച്ചത്). |
| `hasThumbnail` | `boolean` | തംബ്‌നെയിൽ ഫോട്ടോ ഉള്ളവ മാത്രം. |
| `page` | `integer` | പേജ് നമ്പർ. |
| `limit` | `integer` | ഓരോ പേജിലെയും എണ്ണം (പരമാവധി `20`). |

### ഉദാഹരണം

```bash
curl -X GET "https://api.festie.app/public-api/v1/news?page=1&limit=5" \
  -H "X-API-Key: YOUR_API_KEY"
```

## ഫോട്ടോ ഗ്യാലറി (Photo Gallery)

ഫെസ്റ്റിവൽ ഫോട്ടോകളും ആൽബങ്ങളും ലഭ്യമാക്കാൻ:

```http
GET /public-api/v1/gallery
```

### Query Parameters

| Parameter | Type | വിവരണം |
| :--- | :--- | :--- |
| `albumId` | `UUID` | നിർദ്ദിഷ്ട ആൽബത്തിലെ ഫോട്ടോകൾ മാത്രം കാണാൻ. |
| `programCode` | `string` | മത്സരത്തിന്റെ കോഡ് (ഉദാ: `LIT-01`) നൽകി ഫോട്ടോകൾ ഫിൽട്ടർ ചെയ്യാൻ. |
| `subFestProgramId` | `UUID` | പ്രോഗ്രാം സിസ്റ്റം ഐഡി നൽകി ഫോട്ടോകൾ ഫിൽട്ടർ ചെയ്യാൻ. |
| `categoryId` | `UUID` | കാറ്റഗറി അടിസ്ഥാനത്തിൽ ഫിൽട്ടർ ചെയ്യാൻ. |
| `page` | `integer` | പേജ് നമ്പർ (ഡിഫോൾട്ട്: `1`). |
| `limit` | `integer` | ഓരോ പേജിലെയും എണ്ണം (പരമാവധി: `20`). |

### ഉദാഹരണം

```bash
curl -X GET "https://api.festie.app/public-api/v1/gallery?limit=10" \
  -H "X-API-Key: YOUR_API_KEY"
```

## പബ്ലിക് ഡൗൺലോഡുകൾ (Downloads)

നിയമാവലികൾ, മാർഗ്ഗരേഖകൾ, ഫോമുകൾ തുടങ്ങിയ ഔദ്യോഗിക ഫയലുകൾ ഡൗൺലോഡ് ചെയ്യാൻ:

```http
GET /public-api/v1/downloads
```

### Query Parameters

| Parameter | Type | വിവരണം |
| :--- | :--- | :--- |
| `search` | `string` | ഫയലിന്റെ പേരോ വിവരണമോ തിരയാൻ. |
| `category` | `string` | ഫയൽ വിഭാഗം (ഉദാ: `Guidelines`, `Schedule`). |
| `page` | `integer` | പേജ് നമ്പർ. |
| `limit` | `integer` | ഓരോ പേജിലെയും എണ്ണം (പരമാവധി `20`). |

### ഉദാഹരണം

```bash
curl -X GET "https://api.festie.app/public-api/v1/downloads?limit=10" \
  -H "X-API-Key: YOUR_API_KEY"
```
