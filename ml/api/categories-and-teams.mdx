മത്സരാർത്ഥികളെ പ്രായം അല്ലെങ്കിൽ ക്ലാസ് അടിസ്ഥാനമാക്കി തിരിച്ചിട്ടുള്ള ഗ്രൂപ്പുകളാണ് കാറ്റഗറികൾ (ഉദാ: സബ് ജൂനിയർ, ജൂനിയർ, ജനറൽ). പങ്കെടുക്കുന്ന ഹൗസുകൾ, ക്ലബ്ബുകൾ അല്ലെങ്കിൽ സ്ഥാപനങ്ങളെയാണ് ടീമുകൾ പ്രതിനിധീകരിക്കുന്നത്.

## കാറ്റഗറികളുടെ ലിസ്റ്റ് (List Categories)

ഒരു സബ് ഫെസ്റ്റിവലിലുള്ള കാറ്റഗറികൾ അറിയാൻ:

```http
GET /public-api/v1/categories
```

### Query Parameters

| Parameter | Type | നിർബന്ധമാണോ | വിവരണം |
| :--- | :--- | :--- | :--- |
| `subFestId` | `UUID` | അല്ല* | സബ് ഫെസ്റ്റ് ഐഡി (*`subFestSlug` നൽകിയിട്ടില്ലെങ്കിൽ). |
| `subFestSlug` | `string` | അല്ല* | സബ് ഫെസ്റ്റ് സ്ലഗ്. |
| `search` | `string` | അല്ല | പേര് തിരയാൻ. |
| `page` | `integer` | അല്ല | പേജ് നമ്പർ (ഡിഫോൾട്ട്: `1`). |
| `limit` | `integer` | അല്ല | ഓരോ പേജിലെയും എണ്ണം (ഡിഫോൾട്ട്: `20`, പരമാവധി: `20`). |
| `sortBy` | `string` | അല്ല | ക്രമപ്പെടുത്തേണ്ട ഫീൽഡ്: `displayOrder`, `name`. |
| `sortOrder` | `string` | അല്ല | ക്രമം: `ASC` അല്ലെങ്കിൽ `DESC`. |

### ഉദാഹരണം

```bash
curl -X GET "https://api.festie.app/public-api/v1/categories?subFestSlug=arts-2026" \
  -H "X-API-Key: YOUR_API_KEY"
```

## ടീമുകളുടെ ലിസ്റ്റ് (List Teams)

ഫെസ്റ്റിവലിൽ പങ്കെടുക്കുന്ന ഹൗസുകൾ അല്ലെങ്കിൽ ടീമുകൾ അറിയാൻ:

```http
GET /public-api/v1/teams
```

### Query Parameters

| Parameter | Type | നിർബന്ധമാണോ | വിവരണം |
| :--- | :--- | :--- | :--- |
| `subFestId` | `UUID` | അല്ല* | സബ് ഫെസ്റ്റ് ഐഡി. |
| `subFestSlug` | `string` | അല്ല* | സബ് ഫെസ്റ്റ് സ്ലഗ്. |
| `search` | `string` | അല്ല | ടീമിന്റെ പേര് തിരയാൻ. |
| `colorCode` | `string` | അല്ല | ടീം കളർ കോഡ് ഫിൽട്ടർ (ഉദാ: `#EF4444`). |
| `hasCandidates` | `boolean` | അല്ല | മത്സരാർത്ഥികളുള്ള ടീമുകൾ മാത്രം കാണിക്കാൻ (`true` അല്ലെങ്കിൽ `false`). |
| `page` | `integer` | അല്ല | പേജ് നമ്പർ (ഡിഫോൾട്ട്: `1`). |
| `limit` | `integer` | അല്ല | ഓരോ പേജിലെയും എണ്ണം (പരമാവധി `20`). |
| `sortBy` | `string` | അല്ല | ക്രമപ്പെടുത്തേണ്ട ഫീൽഡ്: `displayOrder`, `name`. |
| `sortOrder` | `string` | അല്ല | ക്രമം: `ASC` അല്ലെങ്കിൽ `DESC`. |

### ഉദാഹരണം

```bash
curl -X GET "https://api.festie.app/public-api/v1/teams?subFestSlug=arts-2026" \
  -H "X-API-Key: YOUR_API_KEY"
```
