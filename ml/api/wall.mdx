ഫെസ്റ്റിവൽ നടക്കുന്ന ഓഡിറ്റോറിയങ്ങളിലെ വലിയ പ്രൊജക്ടറുകൾ, സ്റ്റേജിലെ LED വാളുകൾ, പ്രധാന കവാടങ്ങളിലെ സ്ക്രീനുകൾ എന്നിവ നിയന്ത്രിക്കാനുള്ള തത്സമയ ഡാറ്റ Festie നൽകുന്നു. ഫെസ്റ്റിവലിലെ സമഗ്ര വിവരങ്ങൾ, ടീം പോയിന്റ് നില, മത്സര വിജയികൾ, വ്യക്തിഗത ചാമ്പ്യന്മാർ, സ്റ്റേജ് ടൈംടേബിളുകൾ, ഫോട്ടോ ഗ്യാലറി എന്നിവ ഒരൊറ്റ കണക്ഷനിലൂടെ വാളിൽ ലഭ്യമാക്കാം.

<Warning>
  **സെർവർ-സൈഡ് കാളിംഗ് പോളിസി (Server-Side Policy)**

  മറ്റ് Festie ഡെവലപ്പർ API-കളെപ്പോലെ, **ബ്രൗസർ HTML-ൽ നിന്നോ ക്ലയന്റ്-സൈഡ് `<script>` ടാഗുകളിൽ നിന്നോ നേരിട്ട് ഈ API കാൾ ചെയ്യാൻ പാടില്ല.** ഇത് നിങ്ങളുടെ `X-API-Key` പരസ്യപ്പെടാൻ ഇടയാക്കും.
  എപ്പോഴും നിങ്ങളുടെ സ്വന്തം സെർവർ വഴിയോ (Node.js, Next.js Server Route, Python തുടങ്ങിയവ) അല്ലെങ്കിൽ സ്ക്രീൻ കൺട്രോളർ ബാക്കെൻഡ് വഴിയോ മാത്രം API കാൾ ചെയ്യുക.
</Warning>

## സംയോജിത വാൾ ഡാറ്റ API (Consolidated Wall API)

സ്റ്റേജ് വാൾ ഡിസ്പ്ലേയ്ക്ക് ആവശ്യമായ എല്ലാ ലൈവ് ഡാറ്റയും ഒരൊറ്റ നെറ്റ്‌വർക്ക് റിക്വസ്റ്റിൽ ലഭ്യമാക്കുന്ന എൻഡ്പോയിന്റ്:

```http
GET /public-api/v1/wall
```

### Query Parameters

| Parameter | Type | നിർബന്ധമാണോ | വിവരണം |
| :--- | :--- | :--- | :--- |
| `subFestSlug` | `string` | അല്ല* | സബ് ഫെസ്റ്റ് സ്ലഗ് (ഉദാ: `arts-2026`). |
| `subFestId` | `UUID` | അല്ല* | സബ് ഫെസ്റ്റ് സിസ്റ്റം ഐഡി. |

*ഒരു പ്രത്യേക സബ് ഫെസ്റ്റിവൽ ടാർഗെറ്റ് ചെയ്യാൻ `subFestSlug` നൽകുന്നത് നല്ലതാണ്.

### ഉദാഹരണം

```bash
curl -X GET "https://api.festie.app/public-api/v1/wall?subFestSlug=arts-2026" \
  -H "X-API-Key: YOUR_API_KEY"
```

## വാൾ സെക്ഷനുകൾക്കായുള്ള പ്രത്യേക API-കൾ

വാളിലെ ഓരോ ഭാഗവും വെവ്വേറെ പോൾ ചെയ്യാനോ കാഷെ ചെയ്യാനോ ആഗ്രഹിക്കുന്നുവെങ്കിൽ താഴെ പറയുന്ന പ്രത്യേക എൻഡ്പോയിന്റുകൾ ഉപയോഗിക്കാം:

### 1. ടീം പോയിന്റ് നിലയും കൗണ്ടുകളും (Leaderboard)
ടീമുകൾ നേടിയ ആകെ പോയിന്റുകൾ, സ്ഥാനങ്ങൾ, ഫെസ്റ്റിവൽ പുരോഗതി എന്നിവ അറിയാൻ:
```http
GET /public-api/v1/summary?subFestSlug=arts-2026
```

### 2. ലൈവ് റിസൾട്ട് ടിക്കർ (Rolling Results)
ഏറ്റവും ഒടുവിൽ പ്രഖ്യാപിച്ച മത്സര വിജയികളെ (1st, 2nd, 3rd, ഗ്രേഡുകൾ) താഴെ ടിക്കറായോ പോപ്പ്-അപ്പായോ കാണിക്കാൻ:
```http
GET /public-api/v1/programme-results?subFestSlug=arts-2026&limit=10
```

### 3. ചാമ്പ്യന്മാരും ടോപ്പർമാരും (Individual Champions)
കലാപ്രതിഭ, കലാതിലകം അല്ലെങ്കിൽ വിഭാഗം തിരിച്ചുള്ള ടോപ്പർമാരെ പ്രദർശിപ്പിക്കാൻ:
```http
GET /public-api/v1/toppers?subFestSlug=arts-2026
GET /public-api/v1/page-toppers?subFestSlug=arts-2026
```

### 4. സ്റ്റേജ് ടൈംടേബിൾ (Schedules)
ഇപ്പോൾ നടക്കുന്ന മത്സരങ്ങളും അടുത്തതായി ആരംഭിക്കുന്നവയും വേദി തിരിച്ച് അറിയാൻ:
```http
GET /public-api/v1/schedules?subFestSlug=arts-2026&scheduledAtFrom=2026-09-08T00:00:00.000Z
```

### 5. ഫോട്ടോ സ്ലൈഡ്‌ഷോ (Photo Gallery)
ഇടവേളകളിലോ ഫലപ്രഖ്യാപനങ്ങളുടെ ഇടയിലോ കാണിക്കാനുള്ള ഹൈ-റെസല്യൂഷൻ ഫെസ്റ്റിവൽ ഫോട്ടോകൾ:
```http
GET /public-api/v1/gallery?subFestSlug=arts-2026&limit=20
```

## റിയൽ-ടൈം സ്ക്രീൻ സ്ട്രീമിംഗ് (SSE)

Festie സ്ക്രീൻ സ്റ്റുഡിയോ ഉപയോഗിക്കുന്ന വേദികൾക്കായി തത്സമയ അപ്‌ഡേറ്റുകൾ സ്ട്രീം ചെയ്യാൻ Server-Sent Events (SSE) ലഭ്യമാണ്:

```http
GET /screen/:screenId/stream
```

- തുടർച്ചയായി കണക്ഷൻ നിലനിർത്തുന്ന SSE സ്ട്രീം (`text/event-stream`).
- അഡ്മിൻ കൺസോളിൽ നിന്ന് സ്റ്റേജ് ഓപ്പറേറ്റർ സീൻ മാറ്റുകയോ, സ്ക്രോളിംഗ് ടിക്കർ സന്ദേശങ്ങൾ നൽകുകയോ ചെയ്യുമ്പോൾ `screen-event` ഉടൻ ട്രിഗർ ചെയ്യപ്പെടുന്നു.
- പ്രോക്സികൾ വഴി കണക്ഷൻ ഡ്രോപ്പ് ആവാതിരിക്കാൻ ഓരോ 25 സെക്കൻഡിലും `heartbeat` അയക്കുന്നു.

```javascript Node.js / Server SSE ഉദാഹരണം
const eventSource = new EventSource("https://api.festie.app/screen/YOUR_SCREEN_ID/stream");

eventSource.addEventListener("screen-event", (event) => {
  const payload = JSON.parse(event.data);
  console.log("പുതിയ സ്ക്രീൻ ഇവന്റ്:", payload);
});

eventSource.addEventListener("heartbeat", () => {
  // കണക്ഷൻ ലൈവ് ആണ്
});
```
