Templates control generated documents such as judgement sheets, participant lists, posters, and certificates.

## Prerequisites

- You have admin or media access.
- You know the document layout your festival needs.

Open `Subfest > Templates`.

<Steps>
  <Step title="Choose template type">
    Select a sheet, poster, certificate, or another available template type.
  </Step>
  <Step title="Create a custom template">
    Use the template editor to design the layout.
  </Step>
  <Step title="Save the template">
    Save the template so it can be used in programme downloads and reports.
  </Step>
  <Step title="Use the template">
    Select it when downloading sheets, reports, certificates, or related documents.
  </Step>
</Steps>
